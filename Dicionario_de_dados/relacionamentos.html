Todos os Relacionamentos e as Cardinalidades

Relacionamentos existentes entre as entidades do modelo de banco de dados.

Relacionamentos

Relacionamento Explicação
DEPARTAMENTO — FUNCIONARIO Um departamento possui vários funcionários; cada funcionário pertence a um departamento.
MARCA — PRODUTO Uma marca pode possuir vários produtos; cada produto está associado a uma marca.
PRODUTO — PRODUTO_SKU Um produto pode possuir várias variações (SKUs); cada SKU pertence a um produto.
COR — PRODUTO_SKU Uma cor pode estar presente em vários SKUs; cada SKU possui uma cor.
TAMANHO — PRODUTO_SKU Um tamanho pode estar presente em vários SKUs; cada SKU possui um tamanho.
PRODUTO_SKU — ESTOQUE Um SKU pode possuir registros de estoque; cada registro de estoque pertence a um SKU.
CLIENTE — VENDA Um cliente pode realizar várias vendas; cada venda está vinculada a um cliente.
FUNCIONARIO — VENDA Um funcionário pode registrar várias vendas; cada venda é registrada por um funcionário.
VENDA — ITEM_VENDA Uma venda pode possuir vários itens; cada item pertence a uma venda.
PRODUTO_SKU — ITEM_VENDA Um SKU pode aparecer em vários itens de venda; cada item representa um SKU.
CLIENTE — PEDIDO_ONLINE Um cliente pode realizar vários pedidos online; cada pedido pertence a um cliente.
PEDIDO_ONLINE — VENDA Um pedido online corresponde a uma venda; cada venda originada pelo canal online corresponde a um pedido online.
TABELA_PRECO — HISTORICO_PRECO Uma tabela de preços pode possuir vários registros históricos; cada registro pertence a uma tabela.
PRODUTO_SKU — HISTORICO_PRECO Um SKU pode possuir vários registros de preços ao longo do tempo; cada registro de preço corresponde a um SKU.
PEDIDO_ONLINE — TROCA_DEVOLUCAO Um pedido pode possuir ocorrências de troca, devolução ou cancelamento; cada ocorrência pertence a um pedido.
FORNECEDOR — PEDIDO_REPOSICAO Um fornecedor pode receber vários pedidos de reposição; cada pedido de reposição é destinado a um fornecedor.
PEDIDO_REPOSICAO — ITEM_PEDIDO_REPOSICAO Um pedido de reposição pode conter vários itens; cada item pertence a um pedido de reposição.
PRODUTO_SKU — ITEM_PEDIDO_REPOSICAO Um SKU pode aparecer em vários pedidos de reposição; cada item representa um SKU solicitado.
