PÁGINA 1

Dicionário de Dados Conceitual

O dicionário de dados apresenta os principais atributos das entidades identificadas no levantamento, descrevendo seus significados, tipos de dados e restrições preliminares.

Observação: as chaves estrangeiras (FK) apresentadas no dicionário possuem finalidade de rastreabilidade preliminar entre as entidades. No modelo conceitual, os vínculos são representados principalmente por meio dos relacionamentos e cardinalidades do DER.

Entidade: CLIENTE

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_cliente INT Identificador único do cliente. PK / Obrigatório
nome_completo VARCHAR(150) Nome completo do cliente cadastrado. Obrigatório
Cnpj_cliente VARCHAR(14) Número do Cadastro Nacional da Pessoa Jurídica (CNPJ) do cliente. UNIQUE
Cpf_cliente VARCHAR(11) Número do Cadastro de Pessoa Física do cliente. UNIQUE
Endereco_cliente VARCHAR(255) Endereço completo informado pelo cliente. Opcional
telefone_cliente VARCHAR(20) Número de telefone utilizado para contato com o cliente. Opcional
Email_cliente VARCHAR(150) Endereço de e-mail do cliente. Opcional
tipo_cliente VARCHAR(10) Define se o cliente é pessoa física ou jurídica, conforme o tipo de atendimento. B2C ou B2B, Obrigatório

Entidade: FUNCIONARIO

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_funcionario INT Identificador único do funcionário. PK / Obrigatório
nome_funcionario VARCHAR(150) Nome do funcionário. Obrigatório
cargo_funcionario VARCHAR(100) Função ou cargo exercido pelo funcionário na organização. Obrigatório
id_departamento INT Identifica o departamento ao qual o funcionário está associado. FK / Obrigatório

Entidade: DEPARTAMENTO

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_departamento INT Identificador único do departamento. PK / Obrigatório
nome_departamento VARCHAR(100) Nome do departamento da organização, como Compras, Logística, Caixa ou Financeiro. Obrigatório

Entidade: PRODUTO

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_produto INT Identificador único do produto. PK / Obrigatório
codigo_produto VARCHAR(50) Código utilizado para identificar o produto no sistema ERP. Obrigatório
descricao_produto VARCHAR(255) Descrição utilizada para identificar o produto. Obrigatório
referencia_produto VARCHAR(50) Código ou referência utilizada para identificar uma referência comercial do produto. Conforme cadastro
colecao_produto VARCHAR(100) Identifica a coleção comercial à qual o produto pertence dentro do ERP. Conforme cadastro
subcolecao_produto VARCHAR(100) Identifica uma subdivisão da coleção do produto. Conforme cadastro
grupo_produto VARCHAR(100) Identifica o grupo de classificação utilizado para organizar produtos semelhantes dentro do ERP. Conforme cadastro
categoria_produto VARCHAR(100) Identifica a categoria comercial atribuída ao produto. Conforme cadastro
tipo_produto VARCHAR(100) Identifica o tipo atribuído ao produto no cadastro do ERP. Conforme cadastro
codigo_ncm VARCHAR(20) Código da Nomenclatura Comum do Mercosul utilizado na classificação fiscal do produto. Conforme cadastro
classificacao_produto VARCHAR(100) Classificação atribuída ao produto no sistema ERP. Conforme cadastro
pais_origem_produto VARCHAR(100) País de origem informado para o produto. Conforme cadastro
codigo_fiscal_produto VARCHAR(50) Código utilizado para identificação fiscal do produto. Conforme cadastro
unidade_tributacao_produto VARCHAR(50) Unidade utilizada para fins de tributação do produto. Conforme cadastro
id_marca INTEGER Identifica a marca relacionada ao produto. FK / Obrigatório

Entidade: PRODUTO_SKU

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_sku INT Identificador único da variação do produto. PK / Obrigatório
Id_produto INT Identifica o produto ao qual a variação está relacionada. FK / Obrigatório
Id_cor INT Identifica a cor associada à variação do produto. FK / Obrigatório
Id_tamanho INT Identifica o tamanho associado à variação do produto. FK / Obrigatório
peso DECIMAL(10,3) Peso cadastrado da variação do produto. Conforme cadastro
altura DECIMAL(10,2) Altura cadastrada da variação do produto. Conforme cadastro
comprimento DECIMAL(10,2) Comprimento cadastrado do produto. Conforme cadastro
quantidade_estoque INT Representa a quantidade disponível daquela variação do produto em estoque. NOT NULL, CHECK (quantidade_estoque >= 0)
data_atualizacao_estoque DATETIME Indica a data e o horário em que a quantidade disponível daquela variação foi atualizada. NOT NULL

Entidade: MARCA

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_marca INT Identificador único da marca. PK / Obrigatório
nome_marca VARCHAR(100) Nome da marca comercializada pela organização. Obrigatório

Entidade: FORNECEDOR

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_fornecedor INT Identificador único do fornecedor. PK / Obrigatório
cnpj_fornecedor VARCHAR(18) Cadastro Nacional da Pessoa Jurídica do fornecedor. Conforme cadastro
razao_social_fornecedor VARCHAR(150) Razão social registrada do fornecedor. Obrigatório
nome_fornecedor VARCHAR(150) Nome pelo qual o fornecedor é conhecido ou utilizado no cadastro da organização. Conforme cadastro

Entidade: COR

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_cor INT Identificador único da cor. PK / Obrigatório
nome_cor VARCHAR(50) Nome utilizado para identificar a cor de uma variação de produto. Obrigatório
hexadecimal VARCHAR(7) Código hexadecimal utilizado para representar a cor. Conforme cadastro

Entidade: TAMANHO

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_tamanho INT Identificador único do tamanho. PK / Obrigatório
sigla_tamanho VARCHAR(30) Identificação do tamanho utilizado no produto, como P, M, G ou outras classificações cadastradas. Obrigatório

Entidade: VENDA

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_venda INT Identificador único da venda. PK / Obrigatório
data_venda DATE Data em que a venda foi realizada. Obrigatório
canal_venda VARCHAR(20) Identifica o canal em que a venda foi realizada. PDV ou Site
desconto_venda DECIMAL(10,2) Desconto aplicado à venda. Conforme autorização da diretoria
forma_pagamento VARCHAR(50) Forma de pagamento utilizada na venda. Obrigatório
status_venda VARCHAR(50) Situação atual da venda. Conforme processo
quantidade_venda INT Registra a quantidade do SKU comercializada na venda. NOT NULL, CHECK (quantidade_venda > 0)
preco_unitario_venda DECIMAL(10,2) Permite registrar o preço pelo qual cada unidade do SKU foi vendida. NOT NULL, CHECK (preco_unitario_venda >= 0)
id_sku INTEGER Identificador do SKU relacionado à venda. Chave Estrangeira (FK)
id_cliente INT Identifica o cliente associado à venda, quando houver cadastro. FK
id_funcionario INT Identifica o funcionário responsável pelo registro da venda. FK / Obrigatório

Entidade: PEDIDO_ONLINE

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_pedido INT Identificador único do pedido online. PK / Obrigatório
data_pedido DATE Data em que o pedido foi realizado. Obrigatório
status_pedido VARCHAR(50) Situação atual do pedido dentro do processo de atendimento. Conforme etapas do pedido
status_pagamento_pedido VARCHAR(50) Situação da aprovação do pagamento do pedido. Conforme processo
codigo_rastreamento_pedido VARCHAR(100) Código utilizado para acompanhar o envio do pedido. Conforme envio
data_envio_pedido DATE Data em que o pedido foi enviado. Conforme processo
data_entrega_pedido DATE Data em que o pedido foi entregue. Conforme processo
id_cliente INT Identifica o cliente responsável pelo pedido online. FK / Obrigatório
id_venda INT Identificador único da venda. FK / Obrigatório

Entidade: TABELA_PRECO

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_tabela_preco INT Identificador único da tabela de preços. PK / Obrigatório
nome_tabela_preco VARCHAR(100) Nome utilizado para identificar a tabela de preços. Obrigatório
tipo_cliente_tabela_preco VARCHAR(10) Identifica o tipo de cliente ao qual a tabela se aplica. B2C ou B2B
canal_venda_tabela_preco VARCHAR(30) Identifica o canal de venda ao qual a tabela de preços está relacionada. Conforme cadastro
data_inicio_tabela_preco DATE Data de início da utilização da tabela. Obrigatório
data_fim_tabela_preco DATE Data de encerramento da utilização da tabela. Pode ser nulo

Entidade: HISTORICO_PRECO

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_historico_preco INT Identificador único do registro histórico de preço. PK / Obrigatório
id_sku INT Identifica a variação do produto cujo preço foi registrado. FK / Obrigatório
id_tabela_preco INT Identifica a tabela de preços à qual o registro pertence. FK / Obrigatório
preco_historico DECIMAL(10,2) Valor do preço atribuído ao produto naquele período. Obrigatório
data_inicio_preco DATE Data a partir da qual o preço passou a ser utilizado. Obrigatório
data_fim_preco DATE Data em que o preço deixou de ser utilizado. Pode ser nulo
preco_produto DECIMAL(10,2) Preço do produto cadastrado. NOT NULL, CHECK (preco_historico >= 0)

Entidade: TROCA_DEVOLUCAO

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_ocorrencia INT Identificador único da ocorrência. PK / Obrigatório
tipo_ocorrencia VARCHAR(30) Identifica o tipo da ocorrência registrada. Troca, Devolução ou Cancelamento
motivo_ocorrencia VARCHAR(255) Motivo informado para a ocorrência. Obrigatório
data_solicitacao_ocorrencia DATE Data em que a solicitação foi realizada. Obrigatório
status_ocorrencia VARCHAR(50) Situação atual da ocorrência. Conforme processo
valor_estorno_ocorrencia DECIMAL(10,2) Valor relacionado ao estorno realizado quando aplicável. Pode ser nulo
id_pedido INT Identifica o pedido online relacionado à ocorrência. FK / Obrigatório

PEDIDO_REPOSICAO

Nome do Campo Tipo de Dado Descrição Restrição / Chave
id_reposicao INTEGER Identificador único do pedido de compra. Chave Primária (PK)
data_reposicao DATE Data em que o pedido de compra foi registrado. Obrigatório
status_reposicao VARCHAR(30) Situação atual do pedido de compra, como aberto, enviado ou concluído. Obrigatório
data_prevista_entrega DATE Data prevista para recebimento dos produtos solicitados. Opcional
quantidade_reposicao INT Registra a quantidade do SKU que está sendo solicitada no pedido de reposição. NOT NULL, CHECK (quantidade_reposicao > 0)
preco_unitario_reposicao DECIMAL(10,2) Registra o preço negociado ou solicitado para cada unidade do SKU na reposição. NOT NULL, CHECK (preco_unitario_reposicao >= 0)
id_sku INTEGER Identificador do SKU relacionado ao pedido de reposição. Chave Estrangeira (FK)
Id_fornecedor INTEGER Identificador do fornecedor responsável pelo pedido de compra. Chave Estrangeira (FK)
